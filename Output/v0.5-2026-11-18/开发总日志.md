# Lyrebird 开发总日志

汇总版本 v0.5。主体改动完成于 2026-11-17，首屏动画重播与本日志于 2026-11-18 收尾。日志涵盖本次连续协作中的全部交付。

## v0.1 仓库核对与启动说明

核对 GitHub main 的 21ce232，阅读 App Router 目录、首页、全局样式、字体、依赖和本地存储实现，整理本地预览方法。项目使用根目录 app/，首页入口通往浮光、独白、个人志和造物。记录了 localStorage 与 IndexedDB 的分工。

## 项目克隆与首次启动

项目落在 G:\CodexOutput\Lyrebird，保留已有 Output。GitHub 网络重试失败后，通过先前下载的副本完成浅克隆，origin 指向原仓库。依照锁文件安装依赖，默认下载源超时后通过 npm 镜像补齐。根据 .env.example 建立本地环境文件，实际启动并打开首页。

## v0.2 本地启动入口

普通 PowerShell 找不到 Codex 自带的 pnpm，新增 Start-Lyrebird.cmd。启动文件直接调用已安装的 Next.js，优先用系统 Node.js，否则使用当前 Codex 自带的 Node.js。其路径依赖当前 Codex 安装版本。运行预览时需保留启动窗口，Ctrl+C 结束服务。

## v0.3 首页滚轮和背景功能

- 首页向下滚一格平滑切到目录，目录顶部向上滚一格回首屏。长目录保持区内正常滚动。
- 新增首页一级导航区块时，为直属区块添加 data-scroll-section，即可按顺序参与切换。
- 首页启用上传背景时，浮光、独白、个人志和造物默认继承。各分区可独立覆盖，或选「跟随首页背景」恢复继承。独白继续按日期保存覆盖。
- 背景支持 JPG、PNG、WebP、GIF、MP4、WebM。文字偏好保存于 localStorage，大文件继续存放 IndexedDB。已有明确选择的分区保留自己的背景。
- 实测上下滚轮、GIF 和 WebM 上传、四个分区继承、覆盖保存与恢复跟随。

## v0.4 首页视频音频、公共预设和入场动效

- 首页增加与设置按钮同风格的音量按钮，默认尝试有声播放，静音偏好在刷新后保留。浏览器拦截有声自动播放时先静音播放，点击音量按钮开启声音。
- 将用户提供的「少女终末旅行ED.mp4」转为保留完整时长及音轨的 720p H.264/AAC 网页版，放在 public/backgrounds/shoujo-ed.mp4，约 24.8 MB。首页预设名称为「少终ED（视频）」。
- 参考指定归档站的动效，为首页增加标题轻抬淡入、分隔线展开和副标题逐步显示。
- 目录卡片首次进入视野时从下方向上浮现，按网格列错开时间。减少动态效果偏好下直接显示。
- 实测公共视频、原始 MP4 上传、有声播放、静音切换和刷新记忆，验证目录定位及卡片动效。

## v0.5 每次返回首屏时重播动效

- 监听页面首屏可见比例，首屏离开后再次进入视野时重新触发标题、分隔线和副标题动效。
- 从目录上滑回首屏即可重播，从功能路由重新进入首页也会播放。
- 将重播范围限定为首屏文字区域，设置按钮及视频继续使用当前状态。
- 浏览器实测首屏到目录再返回，确认首屏对齐到顶部，入场次数从 0 增加到 1 并重新触发动画。
- TypeScript、ESLint 和补丁检查通过。
